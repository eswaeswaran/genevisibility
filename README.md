# genevisibility
This repository contains scripts and instructions to analyze gene-level publication patterns and integrate sequence features, evolutionary constraints, gene age, and disease associations across stratified gene sets.

## Requirements
- Python ( 3.12.3, other versions may also work), with the following dependencies:
  - os, sys
  - SciPy, statmodels
    
- PAML (to assess eolutionary constraint)
  - codeml
 
- R (v.4.5.1)
